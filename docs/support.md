# Hilfe zu Leser

Leser ist ein schlichter PDF-Betrachter für macOS: Er zeigt Dokumente an und verändert sie nie.

## Erste Schritte

PDFs öffnest du per Doppelklick, über „Ablage → Öffnen …“ (⌘O) oder indem du sie auf das Leser-Symbol im Dock ziehst. Soll Leser PDFs immer öffnen, wähle in den Einstellungen „Leser als Standard festlegen“.

## Tastaturkürzel

| Funktion | Kürzel |
|---|---|
| Suchen, Weitersuchen, Rückwärts | ⌘F, ⌘G, ⇧⌘G |
| Suchergebnisse ein- und ausblenden | ⌥⌘F |
| Seitenleiste ein- und ausblenden | ⌃⌘S |
| Seitenleiste: Gliederung, Miniaturen | ⌃⌘1, ⌃⌘2 |
| Vergrößern, Verkleinern, Originalgröße | ⌘+, ⌘-, ⌘0 |
| Seitenbreite, Seitenhöhe, Ganze Seite | ⌘1, ⌘2, ⌘3 |
| Fortlaufend, Einzelseite, Doppelseite, Doppelseite mit einzelner erster Seite | ⌥⌘1 bis ⌥⌘4 |
| Vorherige, nächste Seite | ← und →, auch ⌥⌘↑ und ⌥⌘↓ |
| Erste, letzte Seite | ⌥⌘Pos1, ⌥⌘Ende |
| Gehe zu Seite | ⌥⌘G |
| Ansicht teilen | ⌃⌘T |
| Dokumentinformationen | ⌘I |
| Drucken | ⌘P |

## Häufige Fragen

**Kann ich mit Leser PDFs bearbeiten, ausfüllen oder kommentieren?**
Nein, und das bleibt so. Leser ist bewusst nur ein Betrachter. Für Anmerkungen eignet sich Vorschau oder ein PDF-Editor.

**Ich sehe keine Gliederung.**
Dann enthält das Dokument keine. Wechsle in der Seitenleiste auf Miniaturen (⌃⌘2).

**Die Suche findet nichts, obwohl der Text sichtbar ist.**
Vermutlich ist das PDF eingescannt und enthält keinen Text, sondern nur Bilder. Unter „Ablage → Dokumentinformationen“ steht bei „Durchsuchbarer Text“ dann „Nein“.

**Kann Leser zwei Stellen gleichzeitig zeigen?**
Ja, mit „Darstellung → Ansicht teilen“ (⌃⌘T). In der zweiten Hälfte lässt sich über „Anderes Dokument …“ auch ein zweites PDF öffnen.

**Warum ändert sich das Dokument im Fenster von selbst?**
Leser lädt eine Datei neu, sobald ein anderes Programm sie ändert. Das lässt sich in den Einstellungen abschalten.

**Was bringen mir die Trinkgelder?**
Nichts außer meinem Dank. Sie schalten keine Funktionen frei; Leser ist und bleibt vollständig kostenlos.
